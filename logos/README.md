# marca/logos/

Coloque aqui os arquivos da sua marca. Depois aponte os caminhos na seção **Logo** do `marca/design-guide.md` — é de lá que as skills leem.

O que vale ter:

| Arquivo | Pra que serve |
|---|---|
| `logo.svg` | versão principal, escala sem perder qualidade (peça pro designer, é o formato certo pra web) |
| `logo.png` | versão pra fundo claro, fundo transparente |
| `logo-branco.png` | versão pra fundo escuro, fundo transparente |
| `simbolo.png` | só o símbolo, sem o nome, pra avatar e favicon |
| `foto-perfil.jpg` | sua foto, pra material que sai no seu nome |

Não tem logo ainda? Sem problema. Os modelos de deck e proposta funcionam sem logo, com o nome do negócio em texto.
